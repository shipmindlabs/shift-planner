# shift-planner

Shift planning for field couriers: activity windows, assignment, and cooldown
locks after a refusal.

## Status

Pre-alpha. The public API is not stable yet.

## Installation

```bash
pip install shift-planner
```

## Development

```bash
python -m venv .venv
source .venv/bin/activate
pip install -e .
```
